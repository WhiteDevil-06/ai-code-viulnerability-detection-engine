Sentinel Documentation

Sentinel is a static code vulnerability detection tool designed to identify security risks in Python repositories. It uses a combination of word-level TF-IDF feature vectors, standard-scaled code structure metrics, and custom security indicators to analyze codebases.

account_tree How Sentinel Works

The processing workflow consists of three main stages: Code Preprocessing (cleaning docstrings and comments), Feature Vector Extraction (combining TF-IDF matrices with code structural metrics and custom indicators), and Classifier Prediction. Sentinel evaluates local Python source files or public Git repositories.

Feature Extraction & Fusion

Sentinel processes raw python methods using word-level TF-IDF vectorization (up to 1,000 top features). In addition, it extracts structural code metrics (number of lines, complexity, token count, nesting depth) which are scaled with a standard scaler, and fuses them with deterministic indicators of unsafe constructs (such as direct eval/exec, shell commands, dynamic SQL queries, and templates).

info

DATA SPLIT VALIDATION

To prevent data leakage, structural features must be standard-scaled using parameters fit strictly on the training partition prior to model inference.

Logistic Regression Classifier

The core model uses Logistic Regression fit on fused code features. Predictions are calibrated with an optimal classification threshold to maximize vulnerable recall while maintaining precision.

from app.scanner import CodeScanner

# Initialize CodeScanner (loads vectorizer, standard-scaler, and trained logistic model)
scanner = CodeScanner()

# Scan python code content
code_snippet = "def execute_query(q): return db.execute(q)"
vuln_type, confidence = scanner.scan_code_snippet(code_snippet)

print(f"Type: {vuln_type}, Confidence: {confidence * 100:.1f}%")

terminal Usage & Run Instructions

Start Flask Web Application

Run the local web dashboard for scanning files and repositories.

python main.py

Train Machine Learning Models

Run training pipeline script to fit vectorizers, scalers, and models.

python training/train_models.py

Run Model Evaluations

Evaluate models against the unseen test split and generate metrics.

python training/evaluate.py

Execute Unit Tests

Run the test suite using pytest to verify classification and scan functionality.

python -m pytest
